# Actores del Sistema

| Actor | ¿Qué necesita realizar? |
| :--- | :--- |
| **Socio** | Consultar clases, realizar/cancelar reservas, consultar estado de su membresía, realizar pagos y consultar con el Asistente IA. |
| **Recepcionista** | Registrar socios, gestionar inscripciones, registrar pagos presenciales y tomar asistencia a clases. |
| **Entrenador** | Consultar sus clases asignadas, listar los socios participantes y validar asistencia. |
| **Administrador** | Administrar usuarios, gestionar planes/tarifas, revisar reportes financieros y configurar el sistema. |
| **Asistente IA** | Servicio inteligente que genera recomendaciones de rutinas y responde dudas frecuentes de socios. |
| **Sistema de Caché (Redis)** | Optimizar la entrega de clases disponibles y control de cupos sin sobrecargar la base de datos. |
